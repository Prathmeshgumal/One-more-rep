**Goal:** Rebuild the middle and bottom of the focus set screen as the approved "Two dials" design, with both numbers typable.

**Architecture:** The weight control moves above the numeral as a 44dp ± row and becomes visible whenever a weight is genuinely in play, not just when the catalogue says so. Both the rep numeral and the weight value become pressable, opening a full-size numeric pad rather than the system keyboard — the system keyboard would cover the action bar it is trying to fill in. The three lying navigation labels collapse into a utility row carrying one Session button, a Note button, and the caption the Record button used to hold, which lets the action bar drop from 76dp to 56dp.

**Tech Stack:** React Native 0.87 CLI, zustand (`useActiveSet`), TanStack Query, RNTL 14.

**Design:** Artifact `42b96fad-85ac-4a3d-b326-9287a17dc9a3` — "Two dials", plus the typable amendment agreed in conversation.

## Global Constraints

- React Native CLI only. Android only. No Expo, no iOS, no web.
- Nothing outside `src/theme/tokens.ts` may declare a colour or a font size.
- Every touch target is at least 44dp.
- Prettier 2.8.8 with `bracketSameLine: true`, `bracketSpacing: false`.
- Commit after every task.
- The suite must stay green and unskipped: `npm test`, `npm run typecheck`, `npm run lint`.

### Task 3: Tap the number, type the number

**Files:**
- Create: `src/ui/NumberPad.tsx`
- Modify: `src/features/workout/FocusSet.tsx`, `src/features/workout/SessionScreen.tsx`
- Test: `__tests__/ui/NumberPad.test.tsx`

A custom pad, not a `TextInput`: Android's keyboard covers the bottom third, which is exactly where Record lives, and it brings autocorrect and a layout shift to a screen whose whole argument is that nothing moves. Keys are 64dp. The decimal key exists only in weight mode; reps are integers.

The current value is shown but not accumulated onto — the first key press replaces it. Typing `6` on a field reading `42.5` must give `6`, never `42.56`.

**Interfaces:**
- Produces: `NumberPad({visible, title, value, unit, allowDecimal, min, max, caption, onSubmit, onClose})`, `onSubmit: (value: number) => void`

- [x] **Step 1:** Tests — first key replaces; decimal key absent for integer mode; a second decimal point is ignored; backspace; submit returns the number; out-of-range disables submit.
- [x] **Step 2:** Run, watch them fail.
- [x] **Step 3:** Write the pad.
- [x] **Step 4:** Make the numeral and the weight value pressable in `FocusSet`, both with labels naming what they edit. Wire in `SessionScreen` to `active.setReps` / `active.setWeight` — the absolute setters that already exist for this purpose.
- [x] **Step 5:** Run the suite. Commit.
