Round two · concept-led

Six More Directions

The first six were skins — one skeleton, six palettes. These are six different ideas, each taken from something real in the gym, and in each one the idea changes the interface rather than just its colours. Three screens apiece: today, recording a set, and a finished session.

01

Scoreboard

A powerlifting meet. Three referee lights decide every attempt — white for a good lift, red for a failed one — and that maps exactly onto three sets against a target. You read the lights before you read a single word. Numbers are set like a venue scoreboard: tall, condensed, glowing out of an inset well.

Palette

Type

Saira Condensed 800 · Spline Sans Mono

Idea

Referee lights are the result chip

Shape

Radius 3 · inset wells · glow

02

Blueprint

Your plan is a technical drawing and the targets are dimensions — measured between extension lines, exactly the way a drafted part is annotated. Deviation gets marked in red pencil, the way a site correction is. Grid paper underneath, sheet numbers in the corner, nothing rounded anywhere.

Palette

Type

Archivo Narrow · Spline Sans Mono

Idea

Targets drawn as dimension lines

Shape

Radius 0 · 1px hairlines · grid

03

Zine

A photocopied flyer taped to the gym door. Fat black rules, hard offset shadows, one fluorescent pink, and typewriter figures. Completed exercises get struck through and stamped rather than ticked — the page fills up with evidence as you work, and finishing a session looks like a marked-up sheet.

Palette

Type

Archivo 800 · Courier Prime

Idea

Strike through, don't tick

Shape

Radius 0 · 2.5px rules · 4px offset

04

Enamel

The record book of an old athletic club. Racing green enamel plaques with a brass keyline, cream paper, and Fraunces cut wonky for the headings. Every session is an entry in a ledger someone will read in fifty years — which is the honest description of what this app actually stores.

Palette

Type

Fraunces 800 wonk · Archivo Narrow

Idea

Brass-keyed enamel plaques

Shape

Radius 3 · double keyline · badges

05

Docket

Every workout prints as a till receipt. Dotted leaders run from each exercise to its numbers, dashed tear-lines separate the sections, and the session ends with a double rule and a total — volume, in kilograms, like a bill. Narrow, monospaced, and completely uninterested in looking like an app.

Palette

Type

Courier Prime throughout

Idea

The session is a printed bill

Shape

No boxes · dashed rules · leaders

06

Bauhaus

Primary red, blue and yellow with black rules, and sets drawn as circles you fill in — empty, solid, or blue for a set that beat its target. Each exercise carries a geometric glyph so the list reads as shapes before it reads as words. Colour blocks do the work that cards do elsewhere.

Palette

Type

Space Grotesk 700

Idea

Sets are circles you fill in

Shape

Circles and squares only · 2.5px
